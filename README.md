# Веб-сайт на Flask — личный бренд (AI-ассистенты для бизнеса)

Витрина услуг на Python Flask: hero и блок «кейсы», форма обратной связи, админ-панель заявок, чат-виджет с RAG через **ProxyAPI** (удобно для хостинга в РФ).

## 🚀 Возможности

- **Главная страница** с hero-блоком под нишу AI-ассистентов и чат-ботов
- **Кейсы портфолио** — на сайте показываются опубликованные проекты (см. `content.py`: флаг `published` и порядок `CASES_ORDER`). Сейчас в витрине четыре кейса; дополнительные сценарии (магазин, CRM) остаются в данных и в темах формы «Контакты», но не выводятся в списке кейсов, пока вы их не включите
- **Форма обратной связи** с валидацией и сохранением в БД
- **Админ-панель** с авторизацией для управления заявками
- **Чат-ассистент** в углу экрана: RAG по `data/faqs.json` и `data/*.txt`, память диалога
- **Современный дизайн** с Bootstrap 5 и кастомными стилями
- **Адаптивная верстка** для всех устройств
- **Анимации и hover-эффекты**

## 📋 Требования

- **Python 3.10+** (рекомендуется 3.12; для FAISS и современных зависимостей 3.8 может быть недостаточно)
- pip (менеджер пакетов Python)

## 🛠️ Установка

1. **Клонируйте репозиторий или скачайте проект**

2. **Создайте виртуальное окружение (рекомендуется):**

```bash
python -m venv venv
```

3. **Активируйте виртуальное окружение:**

   - Windows:
   ```bash
   venv\Scripts\activate
   ```

   - Linux/Mac:
   ```bash
   source venv/bin/activate
   ```

4. **Установите зависимости:**

```bash
python -m pip install -r requirements.txt
```

На Windows, если после переноса папки проекта ломается `pip` внутри `venv`, пересоздайте окружение: удалите папку `venv`, выполните `python -m venv venv` заново и снова установите зависимости.

## ▶️ Запуск

Запустите приложение одной командой:

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## 🔐 Доступ к админ-панели

- URL: `http://localhost:5000/admin/login`
- Логин по умолчанию: `admin`
- Пароль по умолчанию: `admin` (как в `config.py`; для продакшена задайте `ADMIN_PASSWORD` в окружении)

**⚠️ ВАЖНО:** В продакшене обязательно измените учетные данные администратора через переменные окружения или в файле `config.py`.

## 🤖 Чат на сайте (RAG)

FAQ-ассистент: данные в `data/` → эмбеддинги → FAISS → ответ через **ProxyAPI** (доступ к OpenAI из РФ) с контекстом и памятью диалога.

1. Зарегистрируйтесь на [ProxyAPI](https://console.proxyapi.ru/), создайте ключ API.
2. Скопируйте `.env.example` в `.env` и укажите `PROXYAPI_KEY`.
3. Соберите индекс (один раз после изменения данных):

```bash
python -m backend.build_index
```

4. Запустите сайт: `python app.py` и откройте чат-виджет в правом нижнем углу.

Без `PROXYAPI_KEY` сайт и формы работают; `/chat` вернёт ошибку 503.

На хостинге в РФ (например, reg.ru) прямой доступ к `api.openai.com` часто недоступен — запросы к моделям идут через [ProxyAPI](https://proxyapi.ru/).

### Переменные окружения для чата

| Переменная | Назначение |
|------------|------------|
| `PROXYAPI_KEY` | Ключ из [личного кабинета ProxyAPI](https://console.proxyapi.ru/keys) (**обязательно** для чата) |
| `PROXYAPI_BASE_URL` | По умолчанию `https://api.proxyapi.ru/openai/v1` (менять только если сменится адрес в документации) |
| `AI_CHAT_MODEL` | Модель для ответов (по умолчанию `gpt-4o-mini`) |
| `AI_EMBEDDING_MODEL` | Модель эмбеддингов (по умолчанию `text-embedding-3-small`) |
| `CHAT_MAX_HISTORY` | Сколько последних сообщений диалога передавать в модель (по умолчанию `10`) |
| `OPENAI_API_KEY` | Устаревшее имя: если задано без `PROXYAPI_KEY`, используется как ключ для того же клиента |

После правок в `data/faqs.json` или `data/*.txt` снова выполните `python -m backend.build_index` (или удалите `data/faiss_index.bin` и `data/faqs_metadata.npy` — индекс пересоберётся автоматически при следующем запросе к чату).

### Проверка после деплоя

Эндпоинт `GET /health` возвращает `{"status": "ok"}` — удобно для мониторинга на VPS.

## 🎨 Технологии

- **Backend:**
  - Flask 3.0.0
  - Flask-Login (авторизация)
  - Flask-WTF (формы и CSRF защита)
  - SQLAlchemy (работа с БД)
  - SQLite (база данных)
  - OpenAI Python SDK + **ProxyAPI** (эмбеддинги и чат)
  - FAISS (`faiss-cpu`), NumPy

- **Frontend:**
  - Bootstrap 5.3.2
  - Bootstrap Icons
  - Кастомный CSS с анимациями
  - Vanilla JavaScript

## 📝 Основные функции

### Форма обратной связи

- Валидация всех полей на сервере и клиенте
- Сохранение заявок в базу данных
- Уведомления об успешной отправке
- Защита от CSRF атак

### Админ-панель

- Авторизация администратора
- Просмотр всех заявок
- Отметка заявок как "прочитано"
- Удаление заявок
- Статистика (всего заявок, непрочитанных, прочитанных)

### Кейсы

- Описания и порядок — в `content.py` (`CASES_DATA`, `CASES_ORDER`, поле `published`)
- Детальные страницы только для опубликованных кейсов
- Карточки на главной и на `/cases` — общий шаблон `templates/partials/case_card.html`

## 🔧 Настройка

### Изменение учетных данных администратора

1. **Через переменные окружения (рекомендуется):**

```bash
# Windows
set ADMIN_USERNAME=your_username
set ADMIN_PASSWORD=your_password

# Linux/Mac
export ADMIN_USERNAME=your_username
export ADMIN_PASSWORD=your_password
```

2. **Или измените в `config.py`:**

```python
ADMIN_USERNAME = 'your_username'
ADMIN_PASSWORD = 'your_password'
```

### Изменение секретного ключа

В продакшене обязательно измените `SECRET_KEY` в `config.py` или через переменную окружения:

```bash
set SECRET_KEY=your-secret-key-here
```

## 🐛 Решение проблем

### Ошибка при установке зависимостей

Убедитесь, что используете **Python 3.10+**:
```bash
python --version
```

### Ошибка при сборке индекса на Windows (путь с кириллицей)

Индекс сохраняется через `serialize_index` / `deserialize_index`, чтобы обходить ограничения FAISS на путях с не-ASCII символами. Если ошибка повторяется, пересоберите индекс: `python -m backend.build_index`.

### Ошибка подключения к базе данных

База данных создается автоматически при первом запуске. Если возникают проблемы, удалите файл `site.db` и запустите приложение снова.

### Порт 5000 занят

Измените порт в `app.py`:
```python
app.run(debug=True, host='0.0.0.0', port=5001)
```
